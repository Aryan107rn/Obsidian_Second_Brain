# 13. Roman to Integer

**Link:** https://leetcode.com/problems/roman-to-integer/

> [!info] Difficulty
> Easy

## Question

Roman numerals are represented by seven symbols: `I`=1, `V`=5, `X`=10, `L`=50, `C`=100, `D`=500, `M`=1000. Given a roman numeral string, convert it to an integer.

Normally symbols are written largest to smallest (left to right) and their values add up. But there are six special subtractive cases: `I` before `V`/`X` (4, 9), `X` before `L`/`C` (40, 90), `C` before `D`/`M` (400, 900) — a smaller-value symbol placed before a larger one means "subtract the smaller."

## Input / Output

**Example 1**
Input: `s = "III"`
Output: `3`
Explanation: `III = 1 + 1 + 1 = 3`

**Example 2**
Input: `s = "LVIII"`
Output: `58`
Explanation: `L = 50, V = 5, III = 3` → `50 + 5 + 3 = 58`

**Example 3**
Input: `s = "MCMXCIV"`
Output: `1994`
Explanation: `M = 1000, CM = 900, XC = 90, IV = 4` → `1000 + 900 + 90 + 4 = 1994`

## How to solve

Walk through the string left to right, converting each character to its value. For each character, compare its value to the **next** character's value:
- If current < next → this is a subtractive pair (like `I` before `V`), so **subtract** the current value instead of adding it.
- Otherwise → add the current value normally.

This works because in every subtractive case, the smaller symbol always comes immediately before a larger one — so a simple "peek at the next character" check is enough to detect it, without needing to handle each of the six subtractive pairs (IV, IX, XL, XC, CD, CM) as special cases individually.

## Solution

```cpp
class Solution {
public:
    int value(char c) {
        if (c == 'I') return 1;
        if (c == 'V') return 5;
        if (c == 'X') return 10;
        if (c == 'L') return 50;
        if (c == 'C') return 100;
        if (c == 'D') return 500;
        return 1000; // M
    }

    int romanToInt(string s) {
        int ans = 0;
        for (int i = 0; i < s.size(); i++) {
            int curr = value(s[i]);
            if (i + 1 < s.size() && curr < value(s[i + 1])) {
                ans -= curr;   // subtractive case (e.g. I before V)
            } else {
                ans += curr;
            }
        }
        return ans;
    }
};
```

> [!example] Complexity
> O(n) — single pass.
- Space: O(1).

**Common mistake:** forgetting the `i + 1 < s.size()` bounds check before peeking at `s[i+1]` — causes out-of-bounds access on the last character.

**Related pattern:** [[Strings]] — this is a simulation/character-mapping pattern, not one of the heavier string algorithms (KMP, Trie, etc.).
